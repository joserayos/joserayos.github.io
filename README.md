# Portafolio · José Rayos

Marketing digital y performance · Ciudad de Panamá

Sitio: https://joserayos.github.io

## Cómo está armado

- `index.html` — toda la página (estilos, contenido y código en un solo archivo).
- `img/articulos/` — portadas de los artículos de LinkedIn.

## Cómo actualizar

- **Nuevo artículo:** agrega un bloque al inicio de la lista `ARTICLES` (título, fecha, tema, resumen, link y portada) y sube la portada a `img/articulos/`.
- **Nuevo proyecto o pieza:** edita la lista `projects`. Cada pieza es `['Tipo','Título','estilo','ruta/a/imagen-o-video']`.
- **Videos:** usa `.mp4` cortos (menos de 10 MB); se reproducen solos, sin sonido y en bucle.
